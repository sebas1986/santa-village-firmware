# Santa village firmware

Signed firmware builds for the houses of a 3D-printed Christmas village. The source is in a private
repository; the boards download from here and accept only images signed with the owner's key.

- `elf-house/version.txt`: the published version number
- `elf-house/firmware.bin`: Wemos D1 mini (ESP8266) image, RSA-2048 / SHA-256 signed
